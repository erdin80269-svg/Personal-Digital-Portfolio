# Personal Digital Portfolio · 动态个人简历

雷琴韵的个人动态简历网站 —— 3D 虚拟形象 + 交互式卡片 + 中英双语。

## 网站特点

- **3D 虚拟形象**：AI 生成的 3D 卡通形象作为整个页面的视觉主体。
- **交互式板块**：鼠标悬停顶部 5 张卡片，人物会看向对应卡片并切换表情；点击卡片弹出该板块的详细内容（教育背景 / 实习经历 / 项目经验 / 个人技能 / 荣誉奖项）。
- **中英双语一键切换**：右上角按钮切换中英文界面与全部文案，适配国企 / 外企求职场景；也可通过 `?lang=en` 直达英文版。
- **开场动画**：打开网页自动播放裸眼 3D 开场动效，可点击「跳过」。
- **单文件架构**：全站是一个独立的 `index.html`（素材以 Base64 内嵌），可直接浏览器打开，也可嵌入 PPT。
- **响应式适配**：桌面端与移动端均可正常浏览。

## 使用

- 在线访问：https://erdin80269-svg.github.io/Personal-Digital-Portfolio/
- 本地使用：双击 `index.html` 即可在浏览器打开，无需任何依赖。
